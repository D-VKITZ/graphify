# Graphify

Graphify — Force-Directed Playbook Graph fuer DEVKiTZ.

## Features

- Force-directed graph visualization for playbooks and workflows
- Interactive canvas with zoom, pan, and node selection
- Edge traversal and path highlighting
- Data-driven layout with configurable physics
- Export to PNG and SVG

## Tech Stack

HTML5 Canvas · JavaScript ES6+ · No frameworks

## Quick Start

```bash
git clone https://github.com/D-VKITZ/graphify.git
cd graphify
# Open index.html in browser
```
